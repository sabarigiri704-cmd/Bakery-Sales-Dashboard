# 🥐 Bakery Sales Dashboard

## 📊 Project Overview

An interactive Bakery Sales Dashboard created using Microsoft Power BI to analyze bakery sales performance and business insights.

## 📌 Key Performance Indicators

- Total Orders
- Total Revenue
- Total Profit
- Total Quantity

## 📈 Dashboard Features

- Sales by Store Location
- Sales by Payment Method
- Sales by Customer Type
- Top 10 Products by Sales
- Sales by Category
- Order Trend Over Time

## 🛠️ Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization

## 📂 Project Files

- Power BI Dashboard (.pbix)
- Sales Dataset (.xlsx)
